# Teach-Learning — Plateforme d’éducation en ligne

Maquette front-end d’une plateforme d’apprentissage permettant de découvrir des cours et des catégories de formation.

## Fonctionnalités

- Présentation des catégories de cours
- Recherche visuelle de formations
- Mise en avant des cours populaires : Python, JavaScript, mathématiques et dessin
- Sections communauté, certification et services
- Interfaces de connexion et d’inscription
- Formulaire de contact et navigation monopage

## Technologies

- HTML5
- CSS3
- JavaScript

## Structure

- `education.html` : page principale
- `css/edu.css` : mise en forme de l’interface
- `js/js.js` : comportements interactifs
- dossiers d’images et de polices : ressources graphiques

## Lancement

```bash
python -m http.server 8000
```

Ouvrir ensuite `http://localhost:8000/education.html`.

## Contexte

Projet académique consacré à la création d’une interface web éducative. Il s’agit d’un prototype front-end sans API ni persistance des comptes.
